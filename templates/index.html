PUBLIC-KEY CRYPTOSYSTEMS · EXPERIMENT 04

ElGamal Cryptosystem

Explore key generation, encryption and decryption through an interactive, step-by-step laboratory experiment.

gx mod p

Introduction

ElGamal is an asymmetric (public-key) encryption algorithm. The sender uses the recipient’s public key to encrypt a message, and the recipient uses the corresponding private key to decrypt it. Its security is based on the computational difficulty of the discrete logarithm problem. This experiment demonstrates the process through interactive key generation, encryption, and decryption.

Objective

Generate an ElGamal key pair, encrypt a message character by character using its ASCII values, and decrypt the ciphertext. Observe the values and modular arithmetic at every stage, then verify that the recovered message matches the original.

Theory & Algorithm

01

Key generation

  1. Choose prime p > 255 and find a generator g modulo p.
  2. Choose private key x, with 2 ≤ x ≤ p − 2.
  3. Calculate y = gx mod p.
  4. Public key: (p, g, y); private key: x.
02

Encryption

  1. Choose a fresh random k, with 2 ≤ k ≤ p − 2.
  2. Calculate c1 = gk mod p.
  3. Calculate shared key = yk mod p.
  4. For each character m: c2 = (m × shared key) mod p.
03

Decryption

  1. Calculate shared key = c1x mod p.
  2. Find its modular inverse modulo p.
  3. Recover each m = (c2 × shared key−1) mod p.
  4. Convert recovered values back to characters.

Advantages

  • The private key remains with its owner and does not need to be shared with the sender.
  • With fresh valid random values, encrypting the same message can produce different ciphertexts.
  • Its mathematical foundation is related to the discrete logarithm problem.
  • It can be used in public-key encryption applications.

Limitations

  • The ciphertext is larger than the original plaintext.
  • Encryption uses modular arithmetic and can be computationally expensive.
  • Security depends on appropriate parameters, secure random values, and correct implementation.
  • The small prime used in this educational demonstration is not secure for real-world communication.

Applications

  • Public-key encryption of messages or data.
  • Cryptographic systems that require randomized public-key encryption.
  • Certain cryptographic protocols and implementations based on ElGamal.
  • An educational example for learning public-key cryptography, encryption, decryption, and modular arithmetic.

Test Cases

Use the input fields above to test different prime numbers and messages. Each encryption creates a new random k, so encrypting the same message again can produce a different ciphertext while still decrypting to the original.

  • Try a valid prime such as 467 and a short message.
  • Try a composite number, such as 468, to see prime validation.
  • Try a value at or below 255 to see the ASCII-range validation.
  • Try non-ASCII text; its code point must be less than p.

Conclusion

We implemented the ElGamal Cryptosystem in Python and integrated it into a web-based virtual laboratory using Flask. The application demonstrates key generation, encryption, and decryption through interactive inputs and step-by-step calculations. For the tested inputs, the decrypted message matches the original, demonstrating the implementation’s correctness for those test cases. This project helps users understand public-key encryption through practical experimentation.
